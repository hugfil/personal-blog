This site is built with [Astro](https://astro.build) and hosted for free on
GitHub Pages. Every post, project, and note here is just a Markdown file in
the repo — no database, no CMS login, just `git add`, `git commit`, `git push`.

To write a new post, add a file to `src/content/blog/`, following this one as
a template.
